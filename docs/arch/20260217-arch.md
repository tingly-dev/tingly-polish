# Tingly Polish - Architecture Cache

**Date**: 2026-02-17
**Version**: Cache snapshot for development reference

## Project Overview

Chrome extension for AI-powered text translation and polishing using OpenAI-compatible APIs.

## Tech Stack

- **Frontend**: React 18 + TypeScript + MUI
- **Build**: Vite + CRXJS
- **Storage**: Chrome Storage API
- **Messaging**: Chrome Runtime Messaging
- **LLM**: OpenAI SDK (streaming supported)

## Key Types

```typescript
// Core configuration
interface Config {
  apiKey: string;
  baseUrl: string;
  model: string;
  triggerTranslate: string;  // Default: '   ' (triple space)
  triggerPolish: string;
  targetLanguage: string;
  siteMappings: SiteMapping[];
}

// Input element metadata
interface InputElementInfo {
  element: HTMLElement;
  type: 'input' | 'textarea' | 'contenteditable';
  value: string;
  selectionStart?: number;
  selectionEnd?: number;
}

// Message types
type MessageType =
  | 'GET_CONFIG' | 'UPDATE_CONFIG' | 'RESET_CONFIG'
  | 'GET_HISTORY' | 'ADD_HISTORY' | 'CLEAR_HISTORY'
  | 'PROCESS_TEXT' | 'PROCESS_TEXT_STREAM' | 'CANCEL_STREAM'
  | 'STREAM_CHUNK' | 'STREAM_ERROR';
```

## Message Flow

```
┌─────────────────┐     ┌──────────────────┐     ┌────────────────┐
│  Content Script │     │  Service Worker  │     │   LLM Client   │
│                 │     │                  │     │                │
│  PROCESS_TEXT   │────▶│  processText()   │────▶│  translate()   │
│  STREAM         │     │  processStream() │────▶│  stream()      │
│                 │     │                  │     │                │
│  ◀── CHUNK ────│◀────│  ◀── chunks ────│◀────│                │
│                 │     │                  │     │                │
└─────────────────┘     └──────────────────┘     └────────────────┘
```

## Current Issues (2026-02-17)

1. Input monitoring too complex (contenteditable, trix-editor, etc.)
2. Processing preview fixed at right side, not near selection
3. Multiple preview dialogs can appear
4. SiteMappingService adds complexity without clear benefit

## Extension Points

- **LLMClientFactory**: Add new LLM providers
- **SiteMappingService**: Custom input selectors per site (currently unused)
- **TriggerDetector**: Custom trigger patterns
- **PromptBuilder**: Custom prompt templates
